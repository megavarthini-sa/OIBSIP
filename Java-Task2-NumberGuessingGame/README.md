Number Guessing Game

About the Project

This is a Number Guessing Game developed using Java Swing as part of the Oasis Infobyte Java Development Internship.

The computer generates a random number, and the player has to guess it within a limited number of attempts. The game gives hints such as Too High, Too Low, and Correct.

Features

- Three difficulty levels: Easy, Medium, and Hard
- Random number generation
- Limited number of attempts
- Too High and Too Low hints
- Attempt counter
- Game Over message
- Option to play another round
- Score history
- Input validation

Difficulty Levels

Level| Number Range| Attempts
Easy| 1 - 50| 10
Medium| 1 - 100| 7
Hard| 1 - 200| 5

Technologies Used

- Java
- Java Swing

Project Structure

The project contains three Java files:

- GameModel.java – Contains the game logic.
- GameView.java – Creates the graphical user interface.
- Main.java – Runs the application and connects the components.

How to Run

Open the project folder in Command Prompt or Terminal.

Compile the files:

javac GameModel.java GameView.java Main.java

Run the program:

java Main
