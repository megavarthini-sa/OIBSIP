# Online Reservation System

## About the Project

The **Online Reservation System** is a Java-based GUI application developed as part of the **Oasis Infobyte Java Development Internship (OIBSIP)**.

The system allows users to log in, enter passenger and journey details, book train tickets, generate a unique PNR number, and cancel bookings using the PNR number.

The application uses **Java Swing** for the graphical user interface and **SQLite** for storing user, train, and reservation details.

---

## Features

- User Login
- Reservation Form
- Train Number Validation
- Automatic Train Name Retrieval
- Passenger Details Entry
- Class Selection
- Journey Date Entry
- Source and Destination Entry
- Ticket Booking
- Unique PNR Generation
- Booking Confirmation
- PNR-based Booking Cancellation
- Booking Details Retrieval
- Cancellation Confirmation
- Basic Input Validation
- SQLite Database Connectivity
